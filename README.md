# Produção Diária

Protótipo acadêmico de aplicativo desenvolvido para o TCC de Engenharia de Software. O projeto reúne a interface em **Flutter/Dart**, exportada do **FlutterFlow**, e uma estrutura para chamadas de API.

## O que há neste repositório

- Telas de criação de conta, página inicial e seleção de obra.
- Componentes de navegação e interface.
- Estrutura de integração em `lib/backend/api_requests/`.

## Tecnologias

`Flutter` · `Dart` · `FlutterFlow`
